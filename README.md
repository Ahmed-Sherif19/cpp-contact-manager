# Contact Management System

A simple, console-based Contact Management System implemented in C++ for the CSE141 course.

## Features
- **Add Contact**: Add new contacts with a name and phone number.
- **Retrieve Contact**: Search for a contact by name and retrieve their details.
- **Update Contact**: Modify existing contact information.
- **Delete Contact**: Remove a contact from the list.
- **Show All**: Display the entire list of saved contacts.
- **Persistent Storage**: Automatically saves and loads contacts from a `contact_list.txt` file.

## Technologies Used
- C++ (Standard Template Library)
- File I/O (`fstream`)

## How to Run
Compile the code using a standard C++ compiler (like `g++`) and run the executable:

```bash
g++ PROJECT.cpp -o contact_manager
./contact_manager
```
